# Веб-система согласования заявок на оплату

## Студент

**ФИО:** Суржиков Никита
**Группа:** ТРИС-3-23

## Тема проекта

Веб-система согласования заявок на оплату.

## Назначение

Система предназначена для автоматизации процесса создания, проверки, согласования и оплаты заявок на оплату.

Основные роли:

* менеджер;
* руководитель отдела;
* директор.

## Стек

* Vue 3 — клиентская часть;
* ASP.NET Core — серверная часть;
* PostgreSQL — база данных.
